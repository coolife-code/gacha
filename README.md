# 网页扭蛋机微信小程序

一个有趣的网页发现工具，通过扭蛋机形式随机抽取有趣的网站，支持收藏管理、社交分享等功能。

## 🎯 项目特色

- **扭蛋机体验**：每日5次免费抽取，随机发现有趣网站
- **收藏管理**：完善的网址收藏、搜索、标签分类功能
- **社交互动**：关注好友、发布动态、点赞评论
- **精美UI**：采用微信生态设计语言，流畅的动画效果
- **本地存储**：完整的数据本地缓存机制

## 📱 功能模块

### 1. 扭蛋机模块
- 每日免费抽取次数限制
- 扭蛋动画效果（掉落+弹跳）
- 随机网站抽取（普通/稀有/史诗/传说等级）
- 抽取结果展示和收藏功能

### 2. 收藏管理模块
- 网址收藏列表展示
- 搜索和标签筛选功能
- 添加/编辑/删除收藏
- 网址信息管理

### 3. 社交模块
- 动态流展示
- 关注/粉丝系统
- 点赞、评论、分享功能
- 发布动态

### 4. 个人中心模块
- 用户信息展示
- 统计数据（收藏数、抽取数等）
- 设置功能

### 5. 详情页面
- 网站预览功能
- 收藏状态管理
- 分享和二维码生成
- 相关推荐

## 🛠 技术栈

- **框架**：微信小程序原生开发
- **语言**：WXML + WXSS + JavaScript
- **设计**：WeUI设计规范
- **存储**：微信小程序本地存储
- **API**：RESTful API接口（预留）

## 🚀 快速开始

### 环境要求
- 微信开发者工具
- 微信小程序基础库 2.10.0+

### 开发步骤
1. 使用微信开发者工具打开 `frontend` 目录
2. 配置小程序 AppID（测试可使用测试号）
3. 点击编译即可预览效果

### 功能测试
1. **扭蛋功能**：进入首页点击扭蛋机进行抽取
2. **收藏管理**：在收藏页面添加和管理网址
3. **社交功能**：在社交页面查看动态和关注好友
4. **详情页面**：点击任意收藏项查看网站详情

## 🔧 核心配置

### 扭蛋机配置
在 `utils/constants.js` 中配置：
- 每日免费次数
- 网站库数据
- 抽取概率设置

### API配置
在 `utils/api.js` 中配置后端API地址（当前为模拟数据）

## 📊 数据存储

### 本地存储键名
- `collections`：收藏列表
- `gacha_history`：扭蛋记录
- `daily_gacha_count`：每日抽取计数
- `follow_list`：关注列表
- `fans_list`：粉丝列表
- `feed_list`：动态列表
